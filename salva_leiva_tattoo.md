# DEMO WEB — SALVA LEIVA TATTOO

## 1. CONTEXTO DEL PROYECTO

Crear una demo web profesional para un tatuador freelance de Almería.

El objetivo NO es crear una landing page genérica ni una web que parezca generada automáticamente por IA.

La web debe sentirse como el sitio de un **artista/tatuador con identidad visual propia**, con una dirección artística cuidada, moderna, oscura, minimalista y experimental.

Debe transmitir:

* Arte
* Precisión
* Profesionalidad
* Exclusividad
* Personalidad
* Trabajo artesanal
* Estética contemporánea
* Confianza

La web debe estar pensada principalmente para móvil, pero debe funcionar perfectamente en desktop.

# 4. ANIMACIONES

La animación es una parte importante del concepto.

Se pueden utilizar librerías modernas como:

* Framer Motion / Motion
* GSAP si realmente aporta valor
* Lenis para smooth scrolling, si resulta conveniente

No utilizar animaciones porque sí.

Cada animación debe tener una función visual.

La sensación buscada es:

> "La página cobra vida mientras la recorres."

Ejemplos:

* Elementos que aparecen progresivamente al hacer scroll.
* Imágenes que revelan partes de la fotografía.
* Textos grandes que entran desde diferentes direcciones.
* Elementos gráficos que se desplazan lentamente.
* Mandalas que rotan muy sutilmente.
* Imágenes que cambian ligeramente de escala.
* Secciones que parecen descubrirse.
* Transiciones entre bloques.
* Parallax muy sutil.
* Microinteracciones en botones.
* Hover states elegantes.

IMPORTANTE:

No abusar de las animaciones.

Debe sentirse premium, no como una demostración de efectos.

# 5. DIRECCIÓN ARTÍSTICA

## Concepto general

La identidad visual debe partir del universo del tatuaje de Salva:

* Mandalas
* Geometría
* Puntillismo
* Líneas
* Simetría
* Black & Grey
* Texturas de tinta
* Formas circulares
* Precisión matemática

El fondo debe tener personalidad.

NO quiero simplemente:

```text
background-color: black
```

con contenido encima.

Crear una atmósfera visual.

Se pueden utilizar:

* Mandalas muy sutiles
* Patrones geométricos
* Líneas finas
* Texturas
* Formas circulares
* Elementos inspirados en bocetos
* Ruido/grain muy sutil
* Elementos SVG propios

Los elementos de fondo deben tener muy bajo contraste para no perjudicar la legibilidad.

Una buena referencia conceptual sería imaginar:

> Un estudio de tatuajes oscuro convertido en una experiencia digital.

* Botones con aspecto SaaS.

* Emojis.
* Plantillas visuales genéricas.

* Cuadrados o ligeramente rectangulares.
* Bordes definidos.


```text

```

Las cards deben ser minimalistas y, cuando sea posible, utilizar composición editorial en lugar de cajas.
